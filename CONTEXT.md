# FreeShow Presentation Output

This context names the presentation concepts used when FreeShow displays content for audiences, operators, and external destinations.

## Language

**Presentation State**:
The content and playback status associated with a Presentation Output.

**Presentation Output**:
A presentation rendered for an audience-facing display or sent to a Distribution Target.
_Avoid_: Output window, screen output

**Distribution Target**:
A destination that receives a Presentation Output, such as a physical display or external stream.
_Avoid_: Capture type, network output

**Stage Monitor**:
An operator-facing display of presentation information, such as current and next content, that is not itself a Presentation Output.
_Avoid_: Stage output, prompter output
