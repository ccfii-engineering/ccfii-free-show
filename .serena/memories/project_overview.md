FreeShow is an Electron + Svelte 3 + TypeScript presentation app. Electron main code is in `src/electron/`, renderer code in `src/frontend/`, and standalone server apps in `src/server/`; shared IPC contracts are in `src/types/`. `MainOutput.svelte` mounts the standard DOM `Output.svelte`; the custom Pixi/WebGPU renderer, its settings, and playback integrations are removed while normal Electron GPU acceleration remains. For current IPC, Presentation Output state, media scans, portable `.pptx`/PDF imports, CCFII branding, REMOTE media browsing, controller presenter previews, and Serena/Graphify navigation, read `docs/agents/code-navigation.md`. For Remote media or Controller UI work, consult root `PRODUCT.md` and `DESIGN.md`; these describe the modernization scope, not Auth or other Remote destinations. `operator.css` loads only from the Remote and Controller app entries; Stage, Camera, desktop output, and authored slide themes remain outside its scope.
