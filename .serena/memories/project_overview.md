FreeShow is an Electron + Svelte 3 + TypeScript presentation app. Electron main code is in `src/electron/`, renderer code in `src/frontend/`, and standalone server apps in `src/server/`; shared IPC contracts are in `src/types/`. `MainOutput.svelte` mounts the standard DOM `Output.svelte`; the custom Pixi/WebGPU renderer, its settings, and playback integrations are removed while normal Electron GPU acceleration remains. For current IPC, Presentation Output state, media scans, rendered PowerPoint/PDF imports, CCFII branding ownership, and Serena/Graphify navigation, read `docs/agents/code-navigation.md`.
