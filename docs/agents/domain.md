# Domain Docs

This repository has one domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root for the project vocabulary.
- Read relevant architectural decisions under `docs/adr/`.
- If either location does not exist, proceed silently; producer skills create these files only when terminology or decisions are resolved.

## Consumer rules

- Use canonical terms from `CONTEXT.md` in issue titles, specifications, tests, and implementation plans.
- Avoid synonyms explicitly listed under `_Avoid_`.
- Surface any conflict with an existing ADR instead of silently overriding it.
